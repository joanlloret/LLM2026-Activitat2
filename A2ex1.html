HTML i CSS bàsic

Què és HTML?

HTML és el llenguatge de marcatge que s'utilitza per estructurar el contingut d'una pàgina web.

Amb HTML podem crear títols, paràgrafs, llistes, enllaços, imatges i molts altres elements.

Què és CSS?

CSS és el llenguatge que permet definir l'aparença i el disseny dels documents HTML.

HTML s'encarrega principalment de l'estructura, mentre que CSS s'encarrega de la presentació visual.

Conclusió

HTML i CSS són dues tecnologies fonamentals per crear i donar estil a pàgines web.

Amb HTML podem estructurar la informació i amb CSS podem modificar la seva presentació.
